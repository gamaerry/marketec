SOBRE LA PLATAFORMA

Una red estudiantil para mover productos reales dentro del campus.

MarkeTec conecta estudiantes y comercios del ITM para facilitar compra, venta y trueque con una experiencia web ligera y accesible.

¿Qué es MarkeTec?

Es una aplicación web orientada a la comunidad del Instituto Tecnológico de Morelia para publicar productos, encontrar ofertas útiles y generar intercambios entre personas que comparten el mismo entorno escolar.

Público objetivo

Está pensada para estudiantes del ITM y comerciantes dentro de la institución que buscan un canal sencillo para compra, venta y difusión de bienes y servicios.
