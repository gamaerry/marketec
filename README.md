# Introducción 

La aplicación web “MarkeTec” tiene como propósito el facilitar la venta y/o intercambio de bienes entre los actuales estudiantes del Instituto Tecnológico de Morelia, 

## Propósito 

Este documento servirá para el control de los requisitos que tendrá la aplicación web que tendrá la función de venta y trueque entre estudiantes del Instituto Tecnológico de Morelia (ITM). 

La principal audiencia del producto son todos los estudiantes del ITM y todo aquel comerciante dentro de la propia institución interesado en la compra/venta de bienes. 

## Alcance

Podrá ser accesado mediante cualquier navegador moderno en los SO Windows, MacOS o Linux. Contará con los módulos de: Homepage, About us, Mapa del ITM, Registro de vendedor e Información de contacto de vendedor.
