Homepage

Esta aplicación web facilita la venta y/o intercambio de bienes entre estudiantes del Instituto Tecnológico de Morelia (ITM).

Propósito

Controlar los requisitos de una plataforma que habilite compra/venta y trueque entre estudiantes y comerciantes dentro del ITM.

Alcance

Accesible desde navegadores modernos en Windows, MacOS o Linux.
